## 01 / Overview

A cross-platform mobile system engineered for real-time student attendance verification and virtual classroom coordination. It combines mobile location telemetry with backend geofencing algorithms to validate physical presence automatically.

## 02 / Key Features

- **Geofenced Attendance**: Validates student GPS coordinates against designated classroom boundary radiuses before logging attendance.
- **Role-Based Access Control**: Separate permission interfaces for administrators, instructors, and students.
- **Virtual Room Sessions**: Dynamic creation of active lecture sessions with live status tracking and anti-spoofing checks.
- **RESTful Telemetry API**: High-throughput Django REST Framework endpoints handling concurrent device updates.

## 03 / Tech Stack

- **Mobile Client**: Flutter (Dart)
- **Backend API**: Django REST Framework (Python)
- **Database**: PostgreSQL with PostGIS extension for spatial queries
